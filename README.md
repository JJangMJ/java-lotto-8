# 우테코 8기 프리코스 3주차 미션 - 로또

## 구현할 기능 목록

### 입력 기능
- **로또 구입 금액 입력**
    - [x] 구입 금액은 1,000원 단위로 입력받는다.


- **당첨 번호 입력**
    - [x] 당첨 번호 6개를 입력받는다.
    - [x] 번호는 쉼표(,)를 기준으로 구분한다.


- **보너스 번호 입력**
    - [x] 보너스 번호 1개를 입력받는다.

---

### 핵심 기능
- **로또 발행**
    - [x] 구입 금액을 기준으로 발행할 로또의 수량을 계산한다.
    - [x] 발행할 로또의 수량만큼 발행한다.
    - [x] 각 로또는 1부터 45사이의 무작위의 숫자들로 구성한다.
    - [x] 숫자들은 오름차순으로 정렬하여 저장한다.


- **발행된 로또와 당첨 번호와 비교**
    - [ ] 발행된 각 로또가 당첨 번호들 중 몇 개의 번호가 일치하는지 계산하고, 당첨 등수를 판별한다.
    - [ ] 일치하는 번호 개수와 보너스 번호 일치 여부에 따라 1등부터 5등까지의 등수 중 하나로 결정한다.
        - 1등 : 6개 번호 일치
        - 2등 : 5개 번호 + 보너스 번호 일치
        - 3등 : 5개 번호 일치
        - 4등 : 4개 번호 일치
        - 5등 : 3개 번호 일치
        - 0~2개의 숫자가 일치하는 경우는 당첨되지 않은 경우로 판단한다.
    - [ ] 등수별 당첨 개수를 누적하여 저장한다.


- **수익률 계산**
    - [ ] 등수별 당첨 개수를 기준으로 총 당첨 상금을 계산한다.
    - [ ] 총 당첨된 상금과 구입 금액을 비교하여 수익률을 계산한다.
    - [ ] 수익률은 소수점 둘째자리에서 반올림한다.

---

### 출력 기능
- **구입한 로또 수량 및 발행된 각 로또의 번호들을 출력**
    - [x] 구입한 로또의 수량을 출력한다.
    - [x] 발행된 각 로또의 번호들을 하나씩 출력한다.


- **당첨 내역 출력**
    - [ ] 발행된 로또 중 몇개의 로또가 당첨되었는지를 등수별로 출력한다.


- **수익률 출력**
    - [ ] 총 수익률을 출력한다.

---

### 예외 처리
- **로또 구입 금액에 대한 예외 처리**
    - [x] 로또 구입 금액이 공백인 경우 예외 처리한다. 
    - [x] 로또 구입 금액이 숫자가 아닌 경우 예외 처리한다.
    - [x] 로또 구입 금액이 음수인 경우 예외 처리한다.
    - [x] 로또 구입 금액이 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.


- **당첨 번호에 대한 예외 처리**
    - [x] 당첨 번호가 공백인 경우 예외 처리한다.
    - [x] 당첨 번호가 6개가 아닌 경우 예외 처리한다.
    - [x] 당첨 번호의 각 숫자들이 1에서 45사이의 숫자가 아닌 경우 예외 처리한다.
    - [x] 당첨 번호 6개 중 중복되는 숫자가 있는 경우 예외 처리한다.
    - [x] 당첨 번호에 숫자가 아닌 값이 있으면 예외 처리한다.


- **보너스 번호에 대한 예외 처리**
    - [x] 보너스 번호가 공백인 경우 예외 처리한다.
    - [x] 보너스 번호가 숫자가 아닌 경우 예외 처리한다.
    - [ ] 보너스 번호가 하나가 아닌 경우 예외 처리한다.
    - [ ] 보너스 번호가 1에서 45 사이의 숫자가 아닌 경우 예외 처리한다.
    - [ ] 당첨 번호에 있는 숫자를 보너스 번호로 입력하면 예외 처리한다.


- 사용자가 잘못된 값을 입력한 경우 예외를 발생시키고, 그 부분부터 다시 입력 받는다.
- 예외 상황 시, 에러 문구는 "[ERROR]"로 시작해야 한다.
